Comandos Git

git init - Inicializa um novo repositório Git

git status - Mostra o status dos arquivos no índice

git add - Adiciona arquivos ao índice para serem commitados

git commit - Cria um novo commit com as alterações

git log - Exibe o histórico dos commits, e as evoluções feitas no repositório

(Branches) git branch - Representa diferentes linhas de desenvolvimento

git pull - Baixa e integra alterações do repositório remoto
